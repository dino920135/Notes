- ## Prompt
	- ### Using Claude
	  ```text
	  請將以下學術論文製作成一個完整的雙欄批註HTML文件，重點呈現論文的論證結構與邏輯層次。
	  【文件要求】
	  輸出單一 .html 文件，包含以下結構：
	  1. 頂部導覽列
	  - 標題：論文名 + 課程訊息
	  - 顏色圖例，對應以下分析維度：
	  • 黃色 = 核心論點/thesis
	  • 紅色 = 關鍵概念/術語
	  • 藍色 = 實證證據/數據
	  • 綠色 = 讓步/反駁處理
	  • 紫色 = 方法論說明
	  2. 章節導航條（sticky，可跳轉各節）
	  3. 主體內容：左右雙欄佈局
	  左欄：英中雙語對照
	  • 每段依以下順序呈現：
	  ① 英文原文（Lora襯線字體）
	  按五類維度高亮標註關鍵內容
	  ② 中文譯文（緊接在英文段落下方，淺米色背景塊+左側細垂直線與英文區分）
	  - 意譯為主，讀起來像中文學術論文
	  - 不逐字直譯，保持中文表達流暢
	  - 不加顏色高亮，保持乾淨
	  • 英中之間以 1px 細分隔線隔開
	  右欄：中文批註（逐段對應）
	  • 每段批註包含：
	  ① 段落功能（如：引出問題/提供證據/反駁異議/總結）
	  ② 邏輯角色（該段落在整體論證鏈中的位置）
	  ③ 值得注意的論證技巧或潛在漏洞
	  4. 底部論證結構總覽
	  - 全文邏輯骨架（問題→論點→證據→反駁→結論）
	  - 作者核心主張一句話版本
	  - 論證最強處 vs 最弱處各一條
	  【設計風格】
	  - 深海軍藍導航列 + 米白紙張底色
	  - 五類維度分色高亮
	  - 字體：內文 Lora，介面 IBM Plex Sans
	  - 中文譯文區塊：淺米色背景(#f0ece2) + 左側細豎線，與英文原文視覺區分，同屬左欄
	  - 批註卡片：左色邊 + 淺背景
	  - 響應式（行動端單欄）
	  ```
